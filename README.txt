【專案結構說明】
/src          - 包含 main.cpp, GameObjects.cpp (核心原始碼)
/include      - 包含 GameObjects.h (標頭檔，內含防重複引入巨集)
/docs         - 包含 專案報告書.pdf, UML類別圖與流程圖
CMakeLists.txt- CMake 編譯設定檔
events.csv    - 遊戲事件資料庫

【編譯與執行說明】
1. 本專案採用 CMake 進行建構。
2. 若使用 VS code ，請自行點擊建置 ，待出現 ｢建置已完成」即可進行編譯。
3. 編譯完成進入遊戲後，依據 Console 介面提示輸入「1234」即可啟動教師授課模擬。
4. 當遭遇「緊急事件」時，請注意畫面倒數秒數，並於精準時間內輸入對應數字以完成校準挑戰。

【最低技術指標達成宣告】
- 物件導向設計：實作 Event(父類別) 與 UrgentEvent(子類別) 之繼承，並透過虛擬函式實作多型。
- 檔案輸入輸出：實作讀取外部 CSV 檔，動態解析並載入事件池。
- 資料結構：使用 std::vector 儲存指標，管理動態配置之事件物件。
- 錯誤處理：使用 try-catch 機制防禦 cin 格式錯誤與邊界溢位，確保 Console 介面永不崩潰。
